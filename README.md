# Pessoas & Vacinas (Trabalho PPM)

Aplicativo mobile/web desenvolvido com **Ionic** e **Angular** (com suporte ao **Capacitor**) para gerenciamento de pessoas e vacinas.

## Tecnologias utilizadas

- [Ionic Framework](https://ionicframework.com/) (`@ionic/angular` 5)
- [Angular](https://angular.io/) 12
- [Capacitor](https://capacitorjs.com/) 3
- TypeScript

## Como executar

1. Instale as dependências:
   ```bash
   npm install
   ```

2. Inicie o servidor de desenvolvimento:
   ```bash
   npm start
   ```
   Ou via Ionic CLI:
   ```bash
   ionic serve
   ```

3. Para gerar o build de produção:
   ```bash
   npm run build
   ```
